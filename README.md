# compliance-llms-hf-taxonomy
This repository contains scripts, data, and artifacts for the taxonomy survey of compliance-oriented Large Language Models (LLMs) on Hugging Face. It includes reproducible search scripts, curated CSV registries, and supplementary materials for the accompanying survey paper.

### How to run
A complete running process, including all commands, is saved in [Copy_of_hg_llm_Collector_finalVersion9_3_2025_GitHub_noToken.ipynb.]([url](https://github.com/Wenjia1215/compliance-llms-hf-taxonomy/blob/main/notebook/Copy_of_hg_llm_Collector_finalVersion9_3_2025_GitHub_noToken.ipynb)), upload [hg_llms_collector_scripts]([(https://github.com/Wenjia1215/compliance-llms-hf-taxonomy/tree/main/hg_llms_collector_scripts]) and "Run all", then you can repeat the experiments.
