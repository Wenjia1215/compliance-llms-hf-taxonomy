# compliance-llms-hf-taxonomy
Taxonomy survey of compliance-oriented Large Language Models (LLMs) on Hugging Face.

This repository contains scripts, data, and artifacts for a taxonomy survey of compliance-oriented Large Language Models (LLMs) on Hugging Face. It provides reproducible search pipelines, curated CSV registries, and supplementary materials for the accompanying survey paper.

### How to Run
A complete workflow, including all commands, is provided in the [Copy_of_hg_llm_Collector_finalVersion9_3_2025_GitHub_noToken](notebook/Copy_of_hg_llm_Collector_finalVersion9_3_2025_GitHub_noToken.ipynb).  
Open the notebook and select **"Run all"** to reproduce the experiments.

All required scripts are located in the [hg_llms_collector_scripts](hg_llms_collector_scripts) folder.

> Note 1: The [scripts](scripts) directory contains the initial version of the collector. These scripts were not used in the final workflow because the results were too broad, but they are included here for reference.
